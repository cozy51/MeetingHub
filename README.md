# Meeting Hub

Meeting Hub は、Teams 会議、1on1、定例会などの記録と、それに紐づく資料・メモ・自分のタスクを一か所で管理する Web アプリです。会議一覧、全文検索、複合フィルター、タスク集約、詳細・編集画面を備え、データはブラウザの `localStorage` に保存します。

## 起動方法

```bash
npm install
npm run dev
```

`http://localhost:3000` を開いてください。本番ビルドは `npm run build`、起動は `npm start` です。

## 主な機能

- 会議の追加・編集・削除、詳細スライドパネル（開始・終了時刻の登録に対応）
- Outlook / Teams の予定（`.ics`）からの会議登録。日付・時間帯・議題・場所・Teams リンク・分類を自動入力し、同じ予定の二重登録を防止
- 今月から3か月分のカレンダー（会議件数、タスク期限、自分／会社の休みの登録）
- 議題、メモ、タスク、分類、タグを対象にしたリアルタイム検索
- 日付、分類、場所、重要度、タスク状態を組み合わせたフィルター
- 今日・今週・重要・未完了ビューとサマリーダッシュボード
- 全会議を横断するタスク一覧とその場での完了切り替え
- ユーザー定義分類の追加・削除
- JSON による全データのバックアップと復元
- Canva スプレッドシートから移行するための CSV インポート（年月日、場所、分類、議題、リンクメモ、メモ、自分タスク、Teamsリンク）
- デスクトップ・モバイル対応

## データ構造

`Meeting` が基本情報を持ち、複数の `MeetingLink` と `MeetingTask` を配列として参照します。分類は `Category` として独立しており、表示名を後から追加できます。型定義は `src/types/index.ts` にあります。

保存処理は `src/data/repository.ts` に集約し、UI コンポーネントが `localStorage` を直接操作しない構成です。初回のみ `src/data/seed.ts` のサンプルデータを投入します。

## バックエンドへの移行

将来 Supabase、SharePoint、SQL Server などへ移行する場合は、`repository` と同じ責務（会議・分類の取得と保存、インポート・エクスポート）を持つ非同期アダプターを作成します。UI 側はリポジトリを Context またはデータ取得ライブラリ経由で注入することで、コンポーネントやドメイン型を変更せず段階的に移行できます。本番運用では認証、ワークスペース ID、楽観的更新、マイグレーションを追加してください。
